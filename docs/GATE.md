# 门：STYLE 自检

> 目的：把「风格/画质度量」从「看起来像」变成**能判红的东西**。
> 位置：`trit-look selfcheck`（本地/CI 同一条命令）。CI 见 `.github/workflows/ci.yml`。

## 1. 判据（七条，任一失败 → exit 1）

| # | 不变量 | 具体判据 | 反例（会被抓住） |
|---|---|---|---|
| G1 | 常数图 | `luma≈v`、`edge=0`、`flat>0.99`、`levels≤1` | 引入偏移/归一化错误 |
| G2 | 确定性 | 同输入两次 `analyze` **逐位相等**（`PartialEq`） | 用了未固定顺序的并行/哈希 |
| G3 | 尺度可分 | 1px 棋盘 vs 16px 块：`stroke` 前者更小、`hf1` 前者更大 | 多尺度剖面退化 |
| G4 | 平滑响应 | 3×3 均值后 `hf1` 下降 ≥20% | 高频项其实测的是低频 |
| G5 | 分组可分 | 高/低对比两组 `contrast` 的 `|d| ≥ 1` | Cohen's d 口径写反/方差算错 |
| G6 | IO 保真 | PNG 写→读→分析，与「量化后的同一数据」一致 | 读取通道/位深处理错 |
| G7 | 方向性 | 横条纹各向异性 >0.8、主方向≈90°；各向同性噪声 <0.3 | 结构张量算错/角度折叠错 |

## 2. 为什么这样设

- **先立「不会错」的底线，再谈「准不准」**：G1/G2/G6 是度量器的正确性，G3/G4/G5 是灵敏度。
  没有 G1–G2，再漂亮的 d 也不可信。
- **G6 用「量化后对照」**：8bit PNG 天生有量化，拿原始浮点当对照会永久红。
  这条曾经在仓内踩过（`selfcheck` 第一次就是它红）。
- **G5 只验机器通路，不验现实可分性**：现实里「动画 vs 写实」的硬边因子实测 d=−0.05（不可分），
  那是**数据结论**，不是门失败；门只保证「若真有两组差异，统计量能报出来」。

## 3. 加新判据的规矩

1. 新判据必须**能构造反例**（写下「什么改动会让它红」），否则不进 selfcheck。
2. 判据阈值要**留余量**：实测值离阈值至少 2 倍，避免数据漂移造成假红。
3. 凡是跨模型比较的指标，**分母口径要写进文档**（例如边界比用均值、不用 p95——p95 会让方向读反）。
4. 新判据先以 `PASS` 进，另开 commits 修到能红；不允许「先红再放宽」。

## 4. 本地怎么跑

```bash
cargo fmt --all -- --check
cargo clippy --all-targets -- -D warnings
cargo test --locked
cargo run --release -- selfcheck      # 打印 6 行 PASS/FAIL，末尾 SELFCHECK_OK 6/6 才算过
```
