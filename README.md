# trit-look

把「观感」变成可复跑的数字：**亮度/对比/饱和/色相熵/细纹/硬边/平坦/级数/雾感/发光/笔触尺度/多尺度能量/边界比/方向性**，
外加一组 **六维风格因子**（笔触 · 级数 · 硬边 · 对比 · 色温 · 饱和）与两组之间的 **Cohen's d**。
附带一道 **门自检**（`selfcheck`），把「这些度量必须成立的不变量」逐条验；CI 里跑不过就红。

## 它是什么 / 不是什么

- 是：一个**确定性的测量器**。同一张图跑两次逐位一致；给参数调优、A/B、生成质量设「可判红的尺子」。
- 不是：分类器。`analyze` 里的量都是启发式描述量；要判「照片/游戏/UI」得另训判别头。

## 用法

```bash
# 全量描述量（含 CSV）
trit-look look ./frames --out features.csv

# 六维风格因子：A 组 vs B 组（Cohen's d）
trit-look style ./calamity --vs ./textures --out style.csv

# 门自检（CI 会跑）
trit-look selfcheck
```

## 六维因子与一个真实 A/B

A = 一段游戏视频抽的 173 帧；B = 1,299 张材质纹理的 128² 裁剪（灰度）。
（命令：`trit-look style A --vs B`）

| 因子 | A | B | Cohen's d |
|---|---|---|---|
| 笔触 | 30.0 ± 4.5 | 6.5 ± 6.7 | **3.63** |
| 级数 | 42.2 ± 10.7 | 17.4 ± 10.6 | **2.32** |
| 硬边 | 0.010 ± 0.009 | 0.012 ± 0.045 | −0.05 |
| 对比 | 0.505 ± 0.153 | 0.173 ± 0.142 | **2.31** |
| 色温 | 0.022 ± 0.141 | 0.000 ± 0.000 | 0.45 |
| 饱和 | 0.474 ± 0.199 | 0.000 ± 0.000 | 6.95 |

**读这张表前必须知道两件事**（否则会误读）：

1. 色温/饱和的 d 是**退化值**：B 组是灰度图，这两项恒为 0。要公平比较得用彩色原图。
2. **硬边不可分**：截图压缩会把线稿磨平，「动画 vs 写实」不能靠这一项。

## 门（gate）

`selfcheck` 跑 6 条不变量，任一失败即 exit 1：

| # | 不变量 | 为什么重要 |
|---|---|---|
| 1 | 常数图：luma≈v、edge=0、flat=1、级数=1 | 度量没有偏移 |
| 2 | 同输入两次**逐位一致** | 可复现，A/B 才可信 |
| 3 | 细/粗图案：笔触分开、hf1 分开 | 「细节尺度」不是摆设 |
| 4 | 3×3 均值平滑后 hf1 明显下降 | 高频量真的在测高频 |
| 5 | 高对比 vs 低对比两组 \|d\|≥1 | 分组统计链路通 |
| 6 | PNG 写盘→读回→分析一致（按量化后对照） | IO 不污染结论 |
| 7 | 横条纹：各向异性 >0.8 且主方向≈90°；噪声 <0.3 | 方向性不是摆设（S6.4） |

CI（`.github/workflows/ci.yml`）在 push/PR 上跑：`fmt --check` → `clippy -D warnings` → `test` → `selfcheck`。

## 局限（先说清，免得被数字骗）

- **笔触尺度是相对量**：带符号自相关降到 1/e 的位移，周期图案约落在 0.3×周期；只适合跨图比较。
- **边界比**用最外圈与内部相邻差的**均值**比；不要用 p95 做分母（会让方向读反，实测过）。
- **小图抖动**：128² 以下方向/尺度类统计方差明显变大，报告要带方差或多次取样。
- **颜色类因子**只对彩色输入有意义；灰度图请忽略色温/饱和。
- 所有量都是**灰度**口径（`0.299R+0.587G+0.114B`），不建模色域/线性光。
